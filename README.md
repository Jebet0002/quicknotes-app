# QuickNotes

QuickNotes is a lightweight web application designed to help you organize your daily tasks and thoughts efficiently across Personal, Work, and Study categories.

## Features
- **Categorized Note Creation**: Add notes with assigned categories (Personal, Work, Study).
- **Live Search**: Instantly filter notes as you type.
- **Form Validation**: Restricts empty submissions and limits notes to 200 characters.
- **Data Persistence**: Notes are saved in browser `localStorage` and persist across page reloads.
- **Responsive Design**: Mobile-friendly layout styled using CSS Flexbox and media queries.
- **Clear All Option**: Bulk removal of all notes with a confirmation prompt.
